- Problem - Given a tree and a target node with value, find all nodes which are at a distance of value away from that target node


- Intuition -
	- Key is in finding the distance of all nodes from the target node
	- The logic is the recursive dfs method along with minimizing dist in each recursion which starts with 'inf'

- Code -
```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, x):
#         self.val = x
#         self.left = None
#         self.right = None


class Solution:
    def distanceK(self, root: TreeNode, target: TreeNode, k: int) -> List[int]:
        self.ls, self.k, self.target = [], k, target

        def depth(root, dist):
            if not root:
                return dist + 1
            if root == self.target:
                dist = 0
            dist = min(dist, depth(root.left, dist + 1))
            prev_dist = dist
            dist = min(dist, depth(root.right, dist + 1))
            if prev_dist != dist:
                depth(root.left, dist + 1)
            if dist == self.k:
                self.ls.append(root.val)
            return dist + 1

        depth(root, dist=float("inf"))
        return self.ls


```
