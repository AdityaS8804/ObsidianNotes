https://leetcode.com/problems/shortest-bridge/description/
- Problem - Given an `nxn` matrix of 0's and 1's, where 0's is sea and 1's is land, an island is a set of connected 1's from the 4 sides. Given exactly 2 islands, find the smallest number of 0's to be flipped to 1's to connect the 2 islands 


- Intuition -
	- Smallest number of flips -> shortest distance between the two islands
	- Find one of the islands - use DFS
		- loop till first 1 is found
		- From there, loop through the adjacent cells on all 4 sides. If one of them is 1, `dfs(that new cell)`
		- To prevent multiple counting, set `grid[new_x][new_y]=2`   
	- Finding the shortest distance - using BFS:
		- In each iteration of previous recursive call, add the new land cell to bfs_queue
		- Set distance=0
		- Loop through bfs_queue till it is not empty
			- For this new element, look for surrounding elements. 
				- If one of them is land, return the distance found -> as we have reached the new island
				- Else if the new cell is sea, add it to new_queue
			- Set distance+=1


- Code -
```python
class Solution:
    def shortestBridge(self, grid: List[List[int]]) -> int:
        # Find one complete island - dfs
        x, y = -1, -1
        for i in range(len(grid)):
            for j in range(len(grid[i])):
                if grid[i][j] == 1:
                    x, y = i, j
                    break
            if x != -1 and y != -1:
                break
        bfs_queue = []

        def dfs(x, y):
            bfs_queue.append((x, y))
            grid[x][y] = 2
            for cur_x, cur_y in [(x + 1, y), (x - 1, y), (x, y + 1), (x, y - 1)]:
                if (
                    0 <= cur_x < len(grid)
                    and 0 <= cur_y < len(grid)
                    and grid[cur_x][cur_y] == 1
                ):
                    dfs(cur_x, cur_y)

        dfs(x, y)
        # Finding shortest distance : BFS
        dist = 0
        while bfs_queue:
            new_queue = []
            for x, y in bfs_queue:
                for cur_x, cur_y in [(x + 1, y), (x - 1, y), (x, y + 1), (x, y - 1)]:
                    if (
                        0 <= cur_x < len(grid)
                        and 0 <= cur_y < len(grid)
                        and grid[cur_x][cur_y] == 1
                    ):
                        return dist
                    elif (
                        0 <= cur_x < len(grid)
                        and 0 <= cur_y < len(grid)
                        and grid[cur_x][cur_y] == 0
                    ):
                        grid[cur_x][cur_y] = -1
                        new_queue.append((cur_x, cur_y))
            bfs_queue = new_queue
            dist += 1
        return 0


```
