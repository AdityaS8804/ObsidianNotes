https://leetcode.com/problems/all-paths-from-source-to-target/description/

- Problem - Given a DAG where `i` can reach `graph[i]` nodes, return a list of all paths from `0` to `n-1` nodes.

- Intuition -
	- DFS approach - keep applying dfs for each of the nodes and appending it to list `path`
	- If the node reached `n-1` append `path` to list `paths`


- Code -
```python
class Solution:
    def allPathsSourceTarget(self, graph: List[List[int]]) -> List[List[int]]:

        paths = []

        def dfs(i, path):
            path.append(i)
            if i == len(graph) - 1:
                paths.append(path[:])
                return
            for x in graph[i]:
                dfs(x, path[:])

        dfs(0, [])
        return paths

```
