https://leetcode.com/problems/surrounded-regions/description/

- Problem - Given `nxm` of Xs and Os, a region is a set of Os surrounded by Xs and no O is in the edge. Replace these to Xs 


- Intuition - 
	- From [[133. Clone Graph]], we know how dfs can be used to find isolated areas within matrix
	- Use this to find the isolated area of 'O's and number them to different regions and store in a dict
	- Loop through each matrix element in dict. If that element is on the edge, remove that entire region
	- Mark the left over Regions as 'X'
	- Replace the other numbered elements to 'O'
- A cleverer approach -
	- First loop through all the edges - first and last row, first and last column. 
	- Apply dfs and mark those as # 
	- Now do dfs for the entire matrix to find 'O' and replace those to 'X'
	- Replace # with 'O'


- Code -
```python
class Solution:
    def solve(self, board: List[List[str]]) -> None:
        """
        Do not return anything, modify board in-place instead.
        """
        m, n = len(board), len(board[0])
        regions = defaultdict(lambda: [])
        rnum = 1

        def dfs(x, y):
            board[x][y] = f"{rnum}"
            regions[f"{rnum}"].append((x, y))
            for cur_x, cur_y in [(x + 1, y), (x - 1, y), (x, y + 1), (x, y - 1)]:
                if 0 <= cur_x < m and 0 <= cur_y < n and board[cur_x][cur_y] == "O":
                    dfs(cur_x, cur_y)

        for i in range(m):
            for j in range(n):
                if board[i][j] == "O":
                    dfs(i, j)
                    rnum += 1
        for r in regions.keys():
            for x, y in regions[r]:
                if x == 0 or x == m - 1 or y == 0 or y == n - 1:
                    regions[r] = []
                    break
        for i in range(m):
            for j in range(n):
                if board[i][j] != "X" and board[i][j] != "O":
                    if regions[board[i][j]] == []:
                        board[i][j] = "O"
                    else:
                        board[i][j] = "X"

```
